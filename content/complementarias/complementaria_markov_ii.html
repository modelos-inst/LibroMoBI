1. Recordatorio del modelo#

Continuamos con el hospital de la sesión anterior: \(B=20\) camas, dos tipos de pacientes y \(b=5\) camas reservadas para tipo 1.

El estado es \(Z(t)=(X(t),Y(t))\), donde \(X(t)\) y \(Y(t)\) representan el número de pacientes de cada tipo. El espacio de estados es

\[ S_Z = \{(i,j) : i \ge 0,\; j \ge 0,\; j \le B-b,\; i+j \le B\}, \]

que tiene 216 estados válidos.

¿Por qué no \(21 \times 16 = 336\)? Si recorriéramos todas las combinaciones \(i \in \{0,\ldots,20\}\), \(j \in \{0,\ldots,15\}\), incluiríamos estados imposibles como \((20, 15)\): 35 pacientes en un hospital de 20 camas. La restricción \(i + j \le B\) los elimina. Por eso no usamos una fórmula aritmética del tipo i * 16 + j para indexar, sino un diccionario que solo contiene los estados válidos, igual que en la semana 8.

Matriz generadora:

\[\begin{split} Q\bigl((i,j),(i',j')\bigr) = \begin{cases} \lambda_1, & \text{si } i' = i+1,\; j' = j,\; i+j < B, \\[1mm] \lambda_2, & \text{si } j' = j+1,\; i' = i,\; i+j < B,\; j < B-b, \\[1mm] i\cdot\mu_1, & \text{si } i' = i-1,\; j' = j,\; i > 0, \\[1mm] j\cdot\mu_2, & \text{si } j' = j-1,\; i' = i,\; j > 0, \\[1mm] 0, & \text{en otro caso.} \end{cases} \end{split}\]

A continuación, se implementa el modelo.

import numpy as np
import matplotlib.pyplot as plt
from jmarkov.ctmc import ctmc

# Parámetros del modelo
B = 20          # capacidad total del hospital (camas)
b = 5           # camas reservadas para pacientes tipo 1
lambda_1 = 6.5  # tasa de llegada tipo 1 (pacientes/hora)
lambda_2 = 3    # tasa de llegada tipo 2 (pacientes/hora)
mu_1 = 2        # tasa de servicio tipo 1 (pacientes/hora)
mu_2 = 1.5      # tasa de servicio tipo 2 (pacientes/hora)

# Espacio de estados: solo los pares (i, j) válidos
estados = []
for i in range(B + 1):
    for j in range(B - b + 1):
        if i + j <= B:
            estados.append((i, j))

num_estados = len(estados)

# Diccionario: par (i, j) -> índice entero en los vectores de probabilidad
mapa_indices = {estado: idx for idx, estado in enumerate(estados)}

def index(i, j):
    # Devuelve el índice entero del estado (i, j). Falla si el estado no es válido.
    return mapa_indices[(i, j)]

print(f"Tamaño del espacio de estados: {num_estados} pares válidos")

Tamaño del espacio de estados: 216 pares válidos

# Construcción de la matriz generadora Q
Q_hospital = np.zeros((num_estados, num_estados))

for (i, j) in estados:
    idx = index(i, j)

    # Llegada de paciente tipo 1: hay cama disponible
    if i + j < B:
        Q_hospital[idx, index(i + 1, j)] = lambda_1

    # Llegada de paciente tipo 2: hay cama disponible y no se supera B - b
    if (i + j < B) and (j < B - b):
        Q_hospital[idx, index(i, j + 1)] = lambda_2

    # Salida de paciente tipo 1 (tasa proporcional al número actual)
    if i > 0:
        Q_hospital[idx, index(i - 1, j)] = i * mu_1

    # Salida de paciente tipo 2 (tasa proporcional al número actual)
    if j > 0:
        Q_hospital[idx, index(i, j - 1)] = j * mu_2

    # Diagonal: la fila debe sumar cero
    Q_hospital[idx, idx] = -Q_hospital[idx].sum()

print("¿Todas las filas suman cero?:", np.allclose(Q_hospital.sum(axis=1), 0))
print(f"Dimensión de Q: {Q_hospital.shape}")

# Crear la cadena y verificar propiedades
hospital_chain = ctmc(Q_hospital)
print(f"¿Es irreducible?: {hospital_chain.is_irreducible()}")
print(f"¿Es ergódica?: {hospital_chain.is_ergodic()}")

¿Todas las filas suman cero?: True
Dimensión de Q: (216, 216)
¿Es irreducible?: True
¿Es ergódica?: True

# Funciones auxiliares que usaremos en toda la sesión
def vector_a_matriz(pi_vec):
    # Convierte el vector de probabilidades en una matriz (i, j). Los estados imposibles quedan en 0.
    M = np.zeros((B + 1, B - b + 1))
    for (i, j) in estados:
        M[i, j] = pi_vec[index(i, j)]
    return M

Regla práctica para toda la sesión: cuando sumes probabilidades, recorre la lista estados (for (i, j) in estados) en lugar de dos ciclos independientes sobre \(i\) y \(j\). Así nunca tocas un estado imposible.

1.1 Repaso: ¿qué hay dentro de \(\pi(t)\)?#

El vector que devuelve transient_probabilities (o steady_state) tiene una entrada por estado. Casi todas las preguntas de esta sesión se reducen a una de estas dos operaciones:

Pregunta

Operación

Probabilidad de un estado, \(P(X(t)=i,\,Y(t)=j)\)

leer una entrada: pi_t[index(i, j)]

Probabilidad de un evento \(A\) (un conjunto de estados)

sumar las entradas de los estados de \(A\)

3. Funciones del estado: valor esperado y varianza#

Ahora definimos una nueva variable:

\[ T(t)=X(t)+Y(t), \]

el número total de pacientes.

A partir de la distribución conjunta podemos calcular:

\[ E[T]=\sum_{(i,j) \in S_Z}(i+j)\,P(X=i,Y=j) \qquad \text{y} \qquad Var(T)=E[T^2]-E[T]^2. \]

La idea importante es que no necesitamos construir una nueva CMTC para estudiar \(T\): podemos obtener sus medidas directamente a partir de la distribución de \((X,Y)\).

Solución alterna:#

# Podríamos definir una función para calcular E[T] y Var[T], con T = X + Y, dada una distribución de probabilidad
def momentos_total(probs):
    esperanza = sum((i + j) * probs[index(i, j)] for (i, j) in estados)
    esperanza_cuadrado = sum((i + j) ** 2 * probs[index(i, j)] for (i, j) in estados)
    varianza = esperanza_cuadrado - esperanza ** 2
    return esperanza, varianza

# Y usarla de manera más compacta para los dos casos
E_2h, var_2h = momentos_total(probs_transitorias_2h)
E_6h, var_6h = momentos_total(probs_transitorias_6h)

print(f"Tras 2 horas:  E[T] = {E_2h:.3f}   Var[T] = {var_2h:.3f}")
print(f"Tras 6 horas:  E[T] = {E_6h:.3f}   Var[T] = {var_6h:.3f}")

Tras 2 horas:  E[T] = 5.091   Var[T] = 5.091
Tras 6 horas:  E[T] = 5.250   Var[T] = 5.250

Para pensar: ¿por qué cambian tan poco los resultados entre 2 y 6 horas? Recuerda lo que viste en la semana 8 con los mapas de calor: ¿en qué momento el hospital ya está prácticamente en estado estable?

4. Estado estable vs. comportamiento transitorio#

En estado estable, la distribución satisface

\[ \pi Q=0, \qquad \sum_{(i,j) \in S_Z}\pi_{(i,j)}=1. \]

Por ejemplo, podemos preguntar por la probabilidad del evento “hay más pacientes tipo 1 que tipo 2”:

\[ P(X>Y)=\sum_{(i,j) \in S_Z,\; i>j}\pi_{(i,j)}. \]

Después podemos comparar ese valor con \(P(X(t)>Y(t))\) a lo largo del tiempo. Esta comparación permite visualizar la diferencia entre transitorio y largo plazo.

Pregunta 3: Calcule la probabilidad de que haya más pacientes tipo 1 que tipo 2 a largo plazo.#

# Definir el vector de probabilidades en estado estable
pi_estable = hospital_chain.steady_state()

# Calcular la probabilidad de que haya más pacientes tipo 1 que tipo 2 en estado estable
prob_mas_1_estable = 0
for (i, j) in estados:
    if i > j:
        prob_mas_1_estable += pi_estable[index(i, j)]

# Forma alternativa:
# prob_mas_1_estable = sum(pi_estable[index(i, j)] for (i, j) in estados if i > j)

print(f"Probabilidad de que haya más pacientes tipo 1 que tipo 2 en estado estable: {prob_mas_1_estable:.6f}")

Probabilidad de que haya más pacientes tipo 1 que tipo 2 en estado estable: 0.625781

Pregunta 4: Genere una gráfica de la probabilidad de que haya más pacientes tipo 1 que tipo 2 en función del tiempo, desde 0 hasta 24 horas. Compare con el valor obtenido en el punto anterior.#

puntos_de_tiempo = np.linspace(0, 24, 100)

probabilidad_mas_tipo_1 = []
for t in puntos_de_tiempo:
    probs_t = hospital_chain.transient_probabilities(t=t, alpha=alpha_vacio)
    prob_mas_1 = sum(probs_t[index(i, j)] for (i, j) in estados if i > j)
    probabilidad_mas_tipo_1.append(prob_mas_1)

plt.figure(figsize=(8, 5))
plt.plot(puntos_de_tiempo, probabilidad_mas_tipo_1, label="P(X > Y) Transitorio", linewidth=2)
plt.axhline(y=prob_mas_1_estable, color='r', linestyle='--', label="P(X > Y) Estado Estable", linewidth=2)
plt.xlabel("Tiempo (horas)")
plt.ylabel("Probabilidad de X > Y")
plt.title("Evolución de la probabilidad de que haya más pacientes tipo 1 que tipo 2")
plt.legend()
plt.grid(True)
plt.show()

5. Dos medidas de otro tipo: ¿cuánto tarda? y ¿cuánto tiempo pasa?#

Hasta ahora todas las preguntas fueron del tipo “¿qué tan probable es algo en el instante \(t\) (o en el largo plazo)?”. Hay dos medidas que responden preguntas distintas y que usarás en las preguntas de mayor elaboración. Aquí solo las presentamos con un ejemplo cada una; en la Guía de referencia (sección 6) de la complementaria de la semana 8 tienes más detalle.

5.1 Tiempo de primera pasada#

¿Cuánto tiempo pasa, en promedio, hasta que el sistema llega por primera vez a un estado objetivo?

En jmarkov se calcula con first_passage_time(target)[inicial]:

  • target es el índice del estado al que se quiere llegar;

  • la función devuelve un array donde cada elemento corresponde a un posible estado inicial;

  • sobre ese array se toma la posición del estado inicial que nos interesa, [inicial].

Como nuestros estados son pares \((i,j)\), usamos index(i, j) para obtener tanto target como inicial.

Ejemplo: partiendo del hospital vacío, ¿cuánto tarda en promedio en llegar por primera vez al estado \((5,5)\)? ¿Y al estado \((15,5)\), que es uno de los estados con el hospital lleno? Es decir, buscamos \(m_{(0,0),(5,5)}\) y \(m_{(0,0),(15,5)}\).

m_00_55 = hospital_chain.first_passage_time(index(5, 5))[index(0, 0)]
m_00_155 = hospital_chain.first_passage_time(index(15, 5))[index(0, 0)]

print(f"Tiempo promedio de (0, 0) a (5, 5):  {m_00_55[0]:,.1f} horas")
print(f"Tiempo promedio de (0, 0) a (15, 5): {m_00_155[0]:,.1f} horas")

Tiempo promedio de (0, 0) a (5, 5):  17.6 horas
Tiempo promedio de (0, 0) a (15, 5): 623,064.6 horas

Fíjate en la diferencia de escala: el hospital alcanza el estado estable en unas pocas horas y llega a \((5,5)\) en menos de un día, pero un estado con el hospital lleno como \((15,5)\) es tan raro que, en promedio, tarda más de 600 000 horas (unos 70 años) en visitarse por primera vez. Converger rápido al estado estable no significa visitar rápido todos los estados.

5.2 Tiempo de ocupación#

Durante un horizonte \([0, T]\), ¿cuánto tiempo pasa el sistema, en promedio, en cada estado? Se obtiene acumulando las probabilidades transitorias en el tiempo:

\[ \int_0^T P\bigl(Z(t)=(i',j') \mid Z(0)=(i,j)\bigr)\,dt. \]

occupation_time(T) devuelve una matriz donde la fila es el estado de origen y la columna el estado donde se mide el tiempo. Para un conjunto de estados, se suman las columnas correspondientes.

Ejemplo: en las primeras 8 horas de operación, partiendo del hospital vacío, ¿cuántas horas en promedio hay al menos 8 camas ocupadas?

T_horizonte = 8
ocupacion = hospital_chain.occupation_time(T=T_horizonte)

fila_vacio = ocupacion[index(0, 0)]   # tiempos partiendo del hospital vacío
print(f"Verificación: la fila suma {fila_vacio.sum():.4f} (debe ser {T_horizonte})")

horas_8_mas = sum(fila_vacio[index(i, j)] for (i, j) in estados if i + j >= 8)
print(f"Horas esperadas con al menos 8 camas ocupadas en [0, {T_horizonte}]: {horas_8_mas:.3f}")

Verificación: la fila suma 8.0000 (debe ser 8)
Horas esperadas con al menos 8 camas ocupadas en [0, 8]: 1.094

Cierre de la complementaria#

Hasta aquí hemos visto las operaciones fundamentales para extraer información de una CMTC:

  1. Leer la probabilidad de un estado o de un evento a partir de \(\pi(t)\) o \(\pi\).

  2. Marginalizar una distribución conjunta.

  3. Calcular medidas de una función del estado (valor esperado y varianza de \(X+Y\)).

  4. Calcular la probabilidad de un evento en estado estable y compararla con su evolución transitoria.

  5. Medir tiempos: cuánto tarda el sistema en llegar a un estado (primera pasada) y cuánto tiempo pasa en él durante un horizonte (ocupación).

En todos los casos el patrón es el mismo: traducir la pregunta a un conjunto de estados y recorrer estados sumando lo que corresponda.
